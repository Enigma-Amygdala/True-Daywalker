# Project stewardship

## Status: original-author development paused

True Daywalker is being released under MIT so others can learn from it, fork it, fix compatibility problems, and continue development if they choose. The original author does **not** currently plan further gameplay updates.

This repo is not advertising an active development team, ongoing compatibility work, guaranteed code review, or a release schedule. The original author may respond to issues or contributions when available but makes no commitment to do so.

Community maintainers may fork the project and distribute their own compatible releases under the MIT terms. Forks should identify themselves as community builds rather than official releases, and should not imply endorsement by the original author or game developer.

## Recommended community priorities

1. Establish an unpacked, independently buildable first-party native source tree, retaining the original 0.3.0 source archive unchanged for provenance.
2. Verify dependency licenses and reproduce the 0.3.0 build and policy/loader tests.
3. Investigate and document compatibility with current game versions with safe failure on unknown builds.
4. Publish version-matched source, build instructions, test results, and checksums with each **new** community binary release.
5. Update community documentation, tests, and compatibility guidance as changes are independently verified.

## Version and provenance boundary

The repository documents the retained first-party **0.3.0** source snapshot. Newer 0.4.x ZIP and binary packages are present, but matching current first-party source has **not** been established in this repository. Do not imply that releasing the 0.3.0 tree makes later 0.4.x binaries reproducibly open source.

## Governance

- Copyright is retained by its respective copyright holders; the MIT License grants permission to use original project materials.
- No contributor license agreement is required; contributors license their own submissions under MIT.
- The original owner keeps control of this repository unless GitHub permissions are separately granted. Fork ownership is independent.
- This maintenance policy may change if a community maintainer volunteers and a new stewardship arrangement is actually agreed.
