TRUE DAYWALKER
Version 0.3.0 Beta
Supported game build: CL-258504

Official binary release:
https://www.nexusmods.com/thebloodofdawnwalker/mods/554

This repository intentionally does not treat a copied binary as source.
Release integrity values are recorded in ../CHECKSUMS.txt.

Public package layout:
- Dawnwalker/Binaries/Win64/version.dll
- Dawnwalker/Binaries/Win64/TrueDaywalker/TrueDaywalker.ini
- Dawnwalker/Binaries/Win64/TrueDaywalker/SelectAppearance.cmd
- Dawnwalker/Binaries/Win64/TrueDaywalker/SelectAppearance.ps1
- Install.cmd / Install.ps1
- Uninstall.cmd / Uninstall.ps1
- README.txt

The official release is a native version.dll proxy and does not require UE4SS
or another external runtime framework. It is restricted to the tested
CL-258504 executable and fails closed on unsupported Dawnwalker.exe hashes.
